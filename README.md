# Kanaderu（カナデル）

> **音楽1曲と写真を放り込むだけ。曲の尺と雰囲気に合ったムービーを完全ブラウザ内処理で自動生成**

Kanaderu は、React 19 + TypeScript + Vite + WebCodecs をベースにした、100% 完全クライアントサイド動作の自動スライドショームービー生成 Web アプリケーションです。

---

## 🚀 特徴

- 🔒 **完全クライアントサイド（プライバシー保護 & サーバー負荷 0%）**: 写真や音楽はサーバーに一切送信されず、すべての解析・レンダリング・MP4 エンコードがお使いのブラウザ・端末内で完結します。
- ⚡ **WebCodecs + mp4-muxer 高速エンコード**: OS ネイティブのハードウェアアクセラレーションを活用した高速 MP4 出力（H.264 + AAC）。
- 🎵 **インテリジェント楽曲解析**: BPM・ビート打点・RMS（音圧）を自動推定し、写真の切り替えタイミングをビートに自動同期。
- ✂️ **楽曲トリミング**: 好きなサビ区間や任意の長さにトリミングして試聴可能。
- 📌 **特定写真の秒数固定（ピン留め）**: 特定の写真だけ「5.0秒」など長めに表示し、残りの写真を自動均等配分。
- 🎨 **6 種類のメリハリ・トランジション**: ビートフラッシュ、クラッシュズーム、プッシュスライド、シネマティック光フレア、暗転、クロスフェード。
- 🎛️ **フェード設定**: 曲頭フェードイン（0.5s〜2.0s）および曲末フェードアウト（1.0s〜4.0s、音声＆映像暗転）。
- 📱 **アスペクト比切替**: 16:9（YouTube / 横向き）と 9:16（LINE / Reels / TikTok / 縦向き）に対応（ぼかし拡大背景自動合成）。
- 🍎 **iPhone 写真 (HEIC) 自動対応**: HEIC/HEIF 画像をブラウザ内で自動高速デコード・最適化。

## 🛠️ 開発・ビルド手順

### 必要な環境
- Node.js 18+
- 推奨ブラウザ: 最新の Google Chrome または Microsoft Edge（WebCodecs H.264/AAC 対応）

### コマンド
```bash
# 依存関係のインストール
npm install

# 開発サーバー起動 (http://localhost:5173)
npm run dev

# ユニットテスト実行 (Vitest)
npm test

# 本番用静的ファイルビルド (dist/ フォルダ生成)
npm run build
```

---

## 📦 さくらのレンタルサーバへのデプロイ

Kanaderu は静的 SPA のため、バックエンド不要で配置するだけで公開できます。

1. `npm run build` を実行
2. 生成された `dist/` フォルダの中身（`index.html`, `assets/`, `.htaccess` など）をさくらサーバーの `www/`（または任意のサブフォルダ）に FTP 等でアップロード
3. さくらのコントロールパネルから **「無料SSL（Let's Encrypt）」** を有効化（WebCodecs に必須）
